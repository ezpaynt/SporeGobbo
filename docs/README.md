## Workspace roles

Project is the sole maintained authoring checkout. Validation is controlled reusable execution, with distinct owned process storage/output. Operations holds private machine/safety configuration and receipts. Archive holds compact immutable recovery. The indexed Authoring area holds the actual planning workbooks and artist reference kit; it is not another Unity project.

Real saves/preferences, Windows account keys and installed shared tools remain at required system locations. No guide grants launch, deletion, publication or acceptance permission.

## Private evidence

`Operations/evidence-index.json` and `Operations/README.md` are the private recovery entry points outside this repository. Resolve an exact historical original-path key through that index to its archive/member/SHA256 or maintained receipt. Relative archive paths resolve from the configured Archive directory. Original absolute paths are provenance, not required restored locations.

Read `Operations/Executions/WorkspaceCloseoutExecution-20261103/REPORT.md` for the actual closeout result and `WorkspaceCloseout-20261103` for its immutable preparation evidence. Missing required evidence is a dependency failure, not permission to bypass a guard.

Git source recovery does not restore private profiles, claims, identities or preferences. Follow setup, restore six empty folders with original GUID descriptors, and obtain fresh reviewed execution records. File reconstruction is not gameplay acceptance. Local archives protect against cleanup mistakes, not loss of this computer.
